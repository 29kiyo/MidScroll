# MidScroll

Windows用の中クリック長押しオートスクロールユーティリティです。
中クリック(マウスホイールクリック)を長押しすると、その時点のカーソル位置を起点として
オートスクロールモードに入ります。起点から上下にカーソルを動かすと、その距離に応じた
速度でスクロールします。ブラウザのオートスクロール機能に近い操作感を、任意のアプリケーション
上で使えるようにするものです。

## 特徴

- 中クリック長押しでオートスクロールモード開始、起点からの距離に応じて速度が変化(離れるほど速い)
- 短い中クリックは通常のクリックとして他アプリにそのまま伝わる
- スクロールモード中は起点付近にEdge風のカーソル(中立/上/下)を表示
- タスクトレイに常駐し、右クリックメニューから機能のON/OFF・自動起動の切替が可能
- 設定はすべて即座に反映され、アプリ再起動後も保持される
- アンチチート検知機能: 主要なアンチチートサービス(EasyAntiCheat、BattlEye、Riot Vanguard等)
  や代表的な対象ゲームの実行を検知すると自動的に一時停止し、終了すると自動的に再開
- カスタム無効化アプリ機能: 任意のアプリケーションを指定して、実行中はMidScrollを
  無効化することができる(アンチチート検知とは完全に独立した別機能)
- どちらの機能もリスト内の項目ごとに個別でON/OFF可能、機能全体のON/OFFも独立して設定可能

## インストール方法

### インストーラーを使う場合(推奨)

1. [Releases](../../releases)から最新の`MidScroll-Setup-vX.Y.Z.exe`をダウンロード
2. ダウンロードしたインストーラーを実行し、画面の指示に従ってインストール
3. インストール完了後、自動的にMidScrollが起動し、タスクトレイにアイコンが表示されます

管理者権限は不要です(ユーザーディレクトリ配下にインストールされます)。
アンインストールは「アプリと機能」またはスタートメニューの「MidScrollをアンインストール」から行えます。

### zipを使う場合(ポータブル運用)

1. [Releases](../../releases)から最新の`MidScroll-vX.Y.Z-win-x64.zip`をダウンロード
2. 任意のフォルダに展開
3. `MidScroll.exe`を実行

インストール不要ですが、自動起動を有効にした場合は展開先のフォルダを移動・削除しないでください
(レジストリにそのパスが登録されます)。

## 使い方

### 基本操作

1. MidScrollを起動すると、タスクトレイにアイコンが表示されます(ウィンドウは表示されません)
2. 任意のアプリケーション上で中クリックを長押しすると、オートスクロールモードに入ります
3. カーソルを上下に動かすと、起点からの距離に応じた速度でスクロールします
4. 再度中クリックすると、モードが終了します
5. 長押し判定時間(既定300ms)未満で指を離した場合は、通常の中クリックとして扱われます

### タスクトレイメニュー

トレイアイコンを右クリックすると、以下の操作ができます。

| メニュー項目 | 内容 |
|---|---|
| 設定を開く... | 設定画面を表示(ダブルクリックでも開けます) |
| 機能を有効にする | MidScrollの動作全体をON/OFF(設定画面を開かずに即切替) |
| PC起動時に自動起動 | 自動起動のON/OFF(設定画面を開かずに即切替) |
| 状態表示 | 現在の動作状態を表示(通常 / 無効(手動) / 一時停止中(アンチチート検知等)) |
| 終了 | MidScrollを終了 |

一時停止中(手動無効・アンチチート検知・カスタム無効化アプリ検知のいずれか)は、
トレイアイコンがグレースケール表示に切り替わります。

### 設定画面

設定画面は3つのタブに分かれています。

#### 全般タブ

| 項目 | 内容 |
|---|---|
| 機能を有効にする | MidScroll全体のON/OFF(トレイメニューと同じ設定) |
| 長押し判定時間 | 中クリックを何ミリ秒(または秒)押し続けるとスクロールモードに入るか(既定300ms) |
| ホイール速度倍率 | スクロール速度全体の倍率(既定1.0倍) |
| PC起動時に自動起動する | サインイン時にMidScrollを自動起動するか |

#### アンチチート検知タブ

MidScrollはグローバルなマウスフックと、スクロール操作を実現するための合成入力
(SendInputによるホイールイベント送信)を使用しています。これらの技術はチート
ツール・マクロツールが使う手法と共通するため、一部のゲームのアンチチートシステムに
よって不正なツールとして誤検知され、最悪の場合アカウントBANなどの対象になる
リスクがあります。これを避けるため、主要なアンチチートサービスや代表的な対象
ゲーム本体の実行を検知すると、MidScrollは自動的に一時停止します。監視対象
プロセスの実行が終了すると自動的に再開します。

- 「アンチチート検知を有効にする」で機能全体をON/OFFできます
- 監視対象プロセスの一覧はチェックボックス付きのリストで表示され、項目ごとに
  個別にON/OFFできます(機能全体はONのまま、特定の項目だけ無効化することも可能)
- テキストボックスへの入力(カンマ区切りで複数可)、または「参照...」ボタンから
  エクスプローラーで実行ファイルを直接選んで追加できます
- 既定では以下のような主要なアンチチートサービス・ゲームが登録されています
  (随時見直しが必要なため、必要に応じて追加・削除してください)
  - EasyAntiCheat(Fortnite、Apex Legendsほか)
  - BattlEye(PUBG、Rainbow Six Siegeほか)
  - Riot Vanguard(Valorant)
  - nProtect GameGuard

#### カスタム無効化アプリタブ

アンチチート検知とは完全に独立した機能です。任意のアプリケーションを指定して、
実行中はMidScrollを無効化できます。ゲーム以外の用途(特定の作業アプリ使用中は
誤操作を防ぎたい、等)にも使えます。

- 「指定したアプリで無効化する」で機能全体をON/OFFできます
- プロセスの追加方法・個別ON/OFFの操作感はアンチチート検知タブと同様です

### 変更の反映タイミング

設定画面で「保存」を押すと、ほとんどの設定は即座に反映されます。アンチチート検知・
カスタム無効化アプリの一覧やON/OFFを変更した場合も、次回の定期チェック(既定3秒間隔)を
待たずに保存直後に再チェックが行われます。

## 既知の制約

- **Riot Vanguard(Valorant用アンチチート)は、Valorant本体を起動していなくても
  PC起動時から常駐します。** そのため、Riot Vanguardをインストールしている環境では、
  Valorantをプレイしていない時でも「アンチチート検知」タブの既定リストにVanguardの
  プロセス(vgc, vgtray, vgk)が含まれている限り、MidScrollは常に一時停止した状態になります。
  Valorantをプレイしない場合や、この挙動が不要な場合は、アンチチート検知タブの一覧から
  該当項目のチェックを外してください。
- アンチチート検知・カスタム無効化アプリの監視は3秒間隔のポーリングで行われます。
  対象プロセスの起動直後から一時停止が反映されるまで、最大で3秒程度のタイムラグが
  発生する場合があります(設定変更直後の再チェックは即時に行われます)。
- Windows専用です。

## アンインストール

- インストーラーでインストールした場合: 「アプリと機能」またはスタートメニューから
  アンインストールしてください。自動起動の登録(レジストリ)もアプリ側で解除されます。
- zip版の場合: MidScrollを終了した上で、展開したフォルダを削除してください。
  自動起動を有効にしていた場合は、事前に設定画面またはトレイメニューで自動起動を
  OFFにしてから削除することを推奨します。
